# Product design handoff

The focused MVP flow is maintained in [SwasthyaPath Bhubaneswar MVP — Safety & Core Flows](https://www.figma.com/design/L7BYsEaLbvpboas5sQsVP2).

The file covers the four safety-critical mobile states that implementation must preserve:

1. anonymous location selection with an always-visible emergency action;
2. structured intake that fails closed until clinician approval;
3. explainable, provenance-labelled facility recommendations and safe empty states;
4. a patient-generated referral handoff that never implies facility acknowledgement.

The existing green identity is retained. Controls use a minimum 44px target, status is never conveyed only through colour, and Odia labels use an Odia-capable font. Maps remain optional so list navigation continues to work on slow connections.

This is an implementation and clinical-review handoff, not approval of clinical wording. Any safety-sensitive copy in the design remains blocked until documented clinician review.
